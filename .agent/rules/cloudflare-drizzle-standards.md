# Cloudflare Workers + D1 + Drizzle ORM Standards

## 1. Type Declarations
- **NEVER** manually create or import an `interface Env { ... }`.
- **ALWAYS** rely on `worker-configuration.d.ts` generated by `wrangler types`.
- The worker application requires `tsconfig.json` to seamlessly merge `worker-configuration.d.ts` into the global scope. Access bindings natively via `c.env.<BINDING>`.

## 2. D1 Migrations
- Standard Drizzle migrations lacking `IF NOT EXISTS` cause destructive failures on overlapping deployments.
- **ALWAYS** use the custom interceptor script (`scripts/migrate-remote.mjs`) when pushing D1 schema updates.
- The lifecycle command `npm run deploy` must explicitly sequence: `build` -> `drizzle-kit generate` -> `migrate-remote.mjs` -> `wrangler deploy`.

## 3. OpenAPI v3.1.0 Standardization
- All Worker API routes must target OpenAPI v3.1.0.
- All HTTP deployments must mount `/openapi.json`, `/swagger`, and `/scalar` instances tied to the central Hono router.
